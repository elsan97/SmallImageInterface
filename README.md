# SII (Small Image Interface)

logo.png

Привет. Это мой пет-проект — формат сжатия изображений для маленьких картинок (иконки, спрайты, пиксель-арт). 

В какой-то момент мне надоело, что обычный PNG занимает слишком много места для простенькой иконки, и я решил написать свой формат с блэкджеком и альфа-каналом. Идея простая: мы ограничиваем палитру (до 256 цветов), находим похожие цвета и склеиваем их (lossy-сжатие), а потом прогоняем через RLE (сжатие сериями одинаковых пикселей).

В итоге картинка 800x600 с кубиками весит 69 КБ вместо 220 КБ (как в PNG). А какая-нибудь простая иконка сожмётся раз в 15.

## Что тут есть

Проект состоит из трёх частей:
1. **Ядро на чистом C** (`sii.c` / `sii.h`) — собирается в `.dll` (или `.so` для линукса). Внутри свой контейнер с чанками (как в PNG) и проверкой CRC32, чтобы файлы не бились.
2. **Редактор на Python** (`paint_sii.py`) — чтобы можно было рисовать картинки прямо в формате `.sii`. Умеет рисовать кистью, стирать ластиком, брать цвет пипеткой и настраивать прозрачность.
3. **Конвертер** (`convert_to_png.py`) — скармливаешь ему PNG, он делает `.sii`.

## Как этим пользоваться

Тебе понадобится Visual Studio (у меня 2019, но подойдёт и новее) и Python 3.

1. Открываешь проект в VS, выбираешь `Release | x64` и жмёшь `F7`. Рядом с проектом появится `SmallImageInterface.dll`.
2. Кидаешь эту DLL в одну папку со скриптами на Python.
3. Если хочешь конвертировать PNG, поставь Pillow: `pip install pillow`.
4. Запускаешь `paint_sii.py` и рисуешь. Или запускаешь конвертер: `python convert_to_png.py картинка.png`.

## Про формат (для тех, кому интересно)

Файл `.sii` — это по сути архив. 
Сначала идёт заголовок (магия `SII1`, размеры, количество чанков). Потом чанк `PALT` (сама палитра цветов) и чанк `DATA` (сжатые индексы пикселей). У каждого чанка есть CRC32, так что если файл побьётся при передаче, декодер это заметит и не упадёт с ошибкой сегментации.

Из-за того, что мы ограничиваем палитру 256 цветами, на фотографиях с плавными градиентами будут видны артефакты (бандинг). Но для пиксель-арта и иконок — самое то.
