# SII Python (sii-image)

Официальная Python-библиотека для чтения и записи формата **SII (Small Image Interface)**. 

Позволяет конвертировать обычные картинки (PNG, JPG) в `.sii` и обратно, используя только чистый Python (без компиляции C-кода).

## Установка

```bash
pip install sii-image
